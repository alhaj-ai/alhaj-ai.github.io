# alhaj-ai.github.io

Personal AI engineering portfolio for **Mohammed Al-Haj** (`https://alhaj-ai.github.io`), built with Next.js 14 (static export), TypeScript, and Tailwind CSS, and deployed automatically via GitHub Pages.

## Local Development

```bash
npm install
npm run typecheck
npm run build
npm run dev
```

Static output is exported to `out/` and deployed from `.github/workflows/deploy.yml` on every push to `main`.
